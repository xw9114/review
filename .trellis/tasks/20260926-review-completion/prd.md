# 知识草稿与复习流程补齐

## Goal

继续优化已有线上系统，补齐资料、AI 草稿、人工审核、已入库知识与复习之间的使用链路，并完成部署验证。

## Known context

- 已配置 Sub2API 模型，已有 RSS/日记资料、主题、草稿生成和人工批准。
- 用户要求最终入库保持手动确认。
- 上轮仅测试了模型连接，尚未完成真实 UI 闭环验收。
- 本轮先检查已实现功能与文档的差距，再冻结可验收范围。

## Requirements

- 完整展示已入库的摘要、难度、要点、题目和来源。
- 核对草稿、原文与批准结果，避免重复生成、覆盖编辑和陈旧内容入库。
- 补齐题目复用及复习入口，使用数据库保存学习结果。
- 生成与同步由用户显式触发，保留人工最终审核。

## Acceptance criteria

- [x] 完整的生成 → 编辑 → 批准 → 阅读/复习链路可验证。
- [x] 错误与重复操作保持一致状态，已有数据向后兼容。
- [x] 测试、前端构建、移动端检查通过。
- [x] 生产备份、部署、健康检查完成。

## Out of scope

- 自动批准、自动丢弃、无人值守的模型调用。
- Embedding 部署、第三方平台登录或新的付费服务。

## Technical notes

- FastAPI + SQLAlchemy + PostgreSQL；Next.js 16。
- 保留现有样式和组件，优先复用来源内容渲染。
- 生产路径 /srv/projects/knowledge-review-system；只更新该项目。
