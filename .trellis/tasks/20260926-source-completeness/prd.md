# 正文补充与草稿输入质量

## Goal / evidence

用户要求继续优化并推进下一步。线上 107 条待整理资料、1 份未批准草稿；示例资料 #86 只有 387 字并以 `[...]` 结尾。先补齐 AI 起草的输入质量，不开启自动批准或 Embedding。

## Frozen scope

- 待整理 RSS 资料显示字数、疑似摘要提示、AI 输入截断提示。
- 手动抓取已保存的公开原文地址，展示候选正文；只有用户确认应用才改变资料。
- 抓取失败可手动粘贴 Markdown/文本；不执行页面脚本、不绕过登录。
- 保留最新订阅内容，支持查看和显式恢复；后续同步不覆盖用户确认的补充正文。
- 正文版本检查阻止并发覆盖；内容变化使旧草稿待重新生成，但保留其文字，不调用模型，不改已入库知识。
- 草稿审核显示当前原文输入范围并链接到正文补充。

## Contracts / safety

- 新增 source content revision、origin、collected snapshot 和 supplement base hash；迁移保留所有现有数据。
- 新增 preview、apply、collected、restore API；仅 pending RSS 可修改。
- preview 无数据库写入；远程 I/O 前释放事务；返回前验证版本、来源地址、状态。
- 抓取逐跳校验公开 IP 并固定连接地址，禁用环境代理，限制时间/响应大小/重定向次数；离线 HTML 交给现有 Crawl4AI 清洗。
- 正文最多 50,000 字符；不静默截断抓取结果；生成模型的已有输入预算保持不变、明确展示。
- 生产验证最多抓取 1 篇公开文章预览；不应用到真实资料、不覆盖草稿 #1、不触发模型。

## Out of scope

自动全量抓取、自动 AI 重新生成、自动批准、Embedding、平台登录、新付费服务、重构用户的领域/主题。
