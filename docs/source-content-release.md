## 使用

1. 在资料收件箱查看字数、疑似摘要和 AI 输入截断提示。
2. 点击“抓取正文预览”，核对内容；如原站拒绝访问，打开原文后用“手动补充正文”粘贴 Markdown/文本。
3. “确认应用正文”才改变本地资料；最新订阅内容仍可查看和恢复。
4. 如已有旧草稿，点击“复核旧草稿”后显式重新生成，人工核对后批准。正文变化不会自动覆盖草稿文字或正式知识点。

范围：仅待整理 RSS 资料可补充；候选上限 50,000 字符。实际模型仍使用已配置的前 12,000 字符预算，界面提示截断。自动抽取不是完整性保证，需核对公式、评论和导航。
后续订阅同步保护补充正文，订阅内容变化时提示人工复核。恢复对应最新订阅，不是全部历史版本。
